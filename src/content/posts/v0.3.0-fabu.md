v0.3.0 发布了。这一版聚焦「人」：通讯录从一张平铺表升级为完整的双栏管理，另外修掉了一批真实的日常使用痛点。

## 这次有什么新东西

- **通讯录双栏管理**：左树 = 四个智能视图（所有联系人 / 自动采集 / 手动添加 / 未分组，带计数）+ 自定义联系组（新建、右键重命名、删除）；右侧列表 ⇄ 详情双态，支持搜索、新增（含手机号）、批量删除，点行进详情视图。
- **联系组与手机号**：联系人可归入多个自定义组；手机号独立字段；同邮箱多账号自动聚合为一行；点联系人即可直达写信台并带入收件人。
- **自动采集开关**：收发信往来的地址默认自动入册，不需要时左树顶部一键关掉（已入册的保留，手动增删和写信补全不受影响）。
- **授权码所见即所存**：账号配置编辑器预填当前授权码 + 小眼睛显隐，改码直接覆盖保存，不再「保存了但不知道存了什么」。
- **改服务器不用删号**：SMTP/IMAP（授权码）账号的服务器与端口可以直接编辑——保存前自动试连，改完清空该账号本地邮件并后台重同步，换服务商端口再也不用删号重加、丢账号设置。
- **一批体验修**：时间显示统一（UTC+8 晚间的往来不再显示成前一天）、设置页加宽（896px → 1152px）、通讯录列表横向可滚不再裁切。

## 升级方式

```bash
winget upgrade nathanpenny520.Nmail   # Windows
brew upgrade nmail                    # macOS (Apple Silicon)
```

PyPI / 命令行用户直接 `uvx --from nmail-app nmail` 运行最新版；也可到 [Releases](https://github.com/nathanpenny520/Nmail/releases) 下载 Windows / macOS / Linux 三平台单文件。

升级后首次启动自动完成数据库迁移（新增联系组两张表），无需任何手动操作。
